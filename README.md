# Mohamed Gamal Mansour — Portfolio

Personal bilingual CV and portfolio website for Mohamed Gamal Mansour.

## Highlights

- Responsive portfolio layout.
- English and Arabic language switcher.
- Light and dark themes.
- Featured systems including Webook Tracking System and Quran Recitation Academy System.
- Direct links to GitHub, LinkedIn, and email.

## Run locally

Open `index.html` in a browser. No build step is required.

## GitHub Pages

Enable GitHub Pages from **Settings → Pages**, choose the `main` branch and the `/ (root)` folder, then save.
